# 电池 ML 前置校验（`battery-ml`，草案 0.1.0）

> **状态：draft。所有阈值未校准。** 只用于在建模前把已知的电池数据陷阱摆到桌面上。

针对电化学储能方向的机器学习任务，当前覆盖：

- **删失**：寿命测试中大量样本未失效，按普通回归处理会高估 RUL → 需生存分析/删失损失；
- **协议不可比**：不同倍率/截止电压/温度下的标签口径不一致，模型会学到协议差异；
- **目标泄漏**：SOH/容量由与特征同源的电压曲线派生；
- **窗口泄漏**：早期预测的输入窗口与标签窗口重叠；
- **切分单位**：按行/循环切分 = 同一电芯跨集；
- **安全交付**：热失控/报警类任务必须带不确定度与可解释性；
- **外推**：新温度/新倍率/新化学体系需单独外推集与适用域；
- **容量匹配**：独立单位 <100 时不上大模型。

## 跑

```bash
node cli/fcr.mjs run --pack packs/battery-ml/pack.json \
  --data packs/battery-ml/data.example.json
```

## 边界

- 本包是**草案**：规则来自领域常识与工程经验，未做系统校准，也没有和真实项目结果对账；
- 电化学机理（SEI 生长、扩散限制、热失控、老化拐点）目前只以"先验"形式出现，没有专门规则；
- 欢迎按 `CONTRIBUTING.md` 提交校准后的版本（需附数据与指标）。
