# 科研 ML 六问前置校验（`sci-ml-six-questions`）

39 条规则，把"建模之前该问的六个问题"变成一条可执行的检查链。

| 组 | 条数 | 作用 |
|---|---|---|
| `missing` | 8 | 六问缺项（缺项不清，不谈模型） |
| `red` | 18 | 红旗：泄漏、指标错配、小样本大模型、黑箱交付、外推、文献异质性等 |
| `candidate` | 10 | 候选模型族（**不是排行榜**） |
| `verdict` | 3 | 结论：信息不足 / 有红旗 / 可进入基线 |

## 跑

```bash
node cli/fcr.mjs run --pack packs/sci-ml-six-questions/pack.json \
  --data packs/sci-ml-six-questions/data.example.json
```

## 六问

1. 目标：任务类型、指标、答案给谁用；
2. 样本：独立单位、有效 N、泄漏风险；
3. 表示：模态、必须保留的结构；
4. 规模：标签比例、数据质量；
5. 先验：对称/守恒/单调/局部/周期/机理/不可行区；
6. 交付：解释/不确定度/外推/成本/延迟/报警。

## 边界

- 红旗是**启发式**，`N<100`、`N<1000` 等阈值是经验值，**未校准**；
- 不替代验证，不保证结论正确；最终以你的数据与实验为准；
- 规则里的 `evidence` 标注了来源等级：`standard` / `literature` / `heuristic`。
